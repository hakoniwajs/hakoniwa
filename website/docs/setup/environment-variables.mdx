Node.js 版では環境変数 (または `.env`) に、Cloudflare 版では `wrangler.jsonc` の `vars` か secret (`wrangler secret put` やダッシュボード) に設定します。

**すべての項目は省略できます。** 何も設定しなくても起動し、ログインのための秘密鍵は自動で生成され、最初の管理者は `/admin/setup` で登録できます。環境変数が必要になるのは、X / Discord ログインやメール送信のように外部サービスの secret が必要な機能を使うときです。

## 認証・管理者

| 環境変数 | 既定値 | 説明 | Cloudflare |
| --- | --- | --- | --- |
| `HAKONIWA_AUTH_SECRET` | なし (自動生成) | ログインのセッションと CSRF トークンの鍵。未設定なら初回起動時にランダムな値を生成してデータベースに保存します。明示する場合は `openssl rand -base64 32` などで生成した 32 バイト以上のランダム文字列 | secret |
| `HAKONIWA_ADMIN_EMAILS` | なし | 管理者とみなすメールアドレス (カンマ区切り)。管理画面の「管理者」で追加した管理者に加えて、常に管理者として扱われます | vars |
| `HAKONIWA_BASE_URL` | なし (リクエストから自動判定) | 公開 URL。OAuth のコールバックと Origin 検査に使います。カスタムドメインやリバースプロキシ配下で明示したいときだけ設定します | vars |
| `HAKONIWA_X_CLIENT_ID` / `HAKONIWA_X_CLIENT_SECRET` | なし | 両方設定すると X (Twitter) ログインが使えるようになります | secret |
| `HAKONIWA_DISCORD_CLIENT_ID` / `HAKONIWA_DISCORD_CLIENT_SECRET` | なし | 両方設定すると Discord ログインが使えるようになります | secret |
| `HAKONIWA_RESEND_API_KEY` | なし | メールログインのメール送信 (Resend)。未設定ならログにリンクを出力するだけになります | secret |
| `HAKONIWA_MAIL_FROM` | `hakoniwa@example.com` | メールの送信元アドレス | vars |
| `HAKONIWA_DEV_LOGIN` | `false` | `true` で開発ログイン (任意のメールアドレスでログイン) を有効にします。**本番では必ず `false`** | vars |

## ゲームの動作

| 環境変数 | 既定値 | 説明 |
| --- | --- | --- |
| `HAKONIWA_MAX_CATCH_UP_TURNS` | Node.js 版は `1`、Cloudflare 版は `3` | 1 回の判定で進める最大ターン数 |
| `HAKONIWA_ADMIN_ENABLED` | `true` | 管理画面 (`/admin`) の有効・無効 |
| `HAKONIWA_DEBUG` | `false` | `true` でトップページに「ターンを進める」ボタンを表示します (管理者のみ。開発用) |

## Cloudflare 版のみ

| 環境変数 | 既定値 | 説明 |
| --- | --- | --- |
| `HAKONIWA_SNAPSHOT_TTL_SEC` | `60` | [KV スナップショットキャッシュ](/setup/kv-cache) の短期 TTL (秒) |
| `HAKONIWA_SNAPSHOT_TTL_IMMUTABLE_SEC` | `2592000` (30 日) | KV スナップショットキャッシュの長期 TTL (秒) |

## 管理画面に移した設定

次の設定は、環境変数ではなく管理画面で変更します。

| 設定 | 変更する場所 |
| --- | --- |
| サイトのタイトル、フッタの管理者名・連絡先・掲示板・トップページ | 管理画面の「サイト設定」 |
| タイムゾーン、追加の NG ワード、島ごとのローカル掲示板 | 管理画面の「サイト設定」 |
| 開始日時、最終ターン、1 ターンの長さ | 「新しいゲームを開始」のフォーム (CLI では `--start-at` / `--final-turn` / `--unit-time`)。開始後は「ゲーム設定」 |
| 管理者 | 管理画面の「管理者」(または `HAKONIWA_ADMIN_EMAILS`) |

:::note
以前のバージョンで使っていた `HAKONIWA_SITE_TITLE`・`HAKONIWA_ADMIN_NAME`・`HAKONIWA_EMAIL`・`HAKONIWA_BBS_URL`・`HAKONIWA_TOPPAGE_URL`・`HAKONIWA_NG_WORDS`・`HAKONIWA_USE_LBBS`・`HAKONIWA_TIMEZONE` は非推奨です。設定したままでも、管理画面の「サイト設定」で保存するまでは初期値として使われます。`HAKONIWA_UNIT_TIME_SEC`・`HAKONIWA_START_AT`・`HAKONIWA_FINAL_TURN` は読まれなくなりました。
:::

## Node.js 版のみ

| 環境変数 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `3000` | サーバーの待ち受けポート |
| `HAKONIWA_DB_PATH` | `./data/hakoniwa.sqlite` | SQLite データベースファイル |
| `HAKONIWA_BACKUP_DIR` | `./data/backups` | バックアップの出力先 |
| `HAKONIWA_TURN_CHECK_INTERVAL_SEC` | `60` | ターン進行を確認する間隔 (秒)。`0` で無効 |
| `HAKONIWA_PUBLIC_DIR` | `@hakoniwajs/core` の `public/` | 画像や CSS を配信するディレクトリ |

コード上の定義は `packages/core/src/bootstrap/config-from-env.ts` (共通)、`packages/node/src/config.ts` (Node.js 版)、`packages/cloudflare/src/snapshot.ts` (KV キャッシュ) にあります。
