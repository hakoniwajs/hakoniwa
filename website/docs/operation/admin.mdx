管理者としてログインすると、`/admin` の管理画面を使えます。

## 管理者

管理者は、管理画面の「管理者」に登録したメールアドレス、または環境変数 `HAKONIWA_ADMIN_EMAILS` に指定したメールアドレスのユーザーです。

- **初期セットアップ (`/admin/setup`)**: 管理者が 1 人もいないときだけ使えます。ログインした状態で開くと、サーバーのログ (Cloudflare なら Worker の Logs、Node.js ならコンソール) にセットアップコードが出力されるので、それを入力すると管理者になれます
- **管理者の追加・削除**: 「管理者」から、ほかのユーザーのメールアドレスを追加・削除できます。管理者が 1 人もいなくなるような削除はできません。環境変数で指定した管理者は、ここからは削除できません

X ログインはメールアドレスを返さないため、X ログインだけのアカウントは管理者にできません。

## ゲームの開始と終了

- **新しいゲームを開始**: ゲーム名・開始日時・最終ターン・1 ターンの長さ (時間・分) を指定してゲームを始めます。すべて省略可能で、名前を省略すると「第 N 回」になります。現在のゲームが無いか、終了しているときだけ実行できます
- **このゲームを終了する**: 進行中のゲームを手動で終了させます (確認のチェックボックス付き)
- **このデータを削除**: 現在のゲームのデータを削除します

ゲームの流れについては [ゲームとシーズン](/operation/season) を参照してください。

## ゲームの状態と一覧

- **現役データ**: 現在のゲームの名前・ID・状態・ターン数・最終更新時刻・開始時刻・最終ターン・1 ターンの長さを表示します
- **ゲーム一覧**: 現在と過去のゲームを、名前・開始・終了・ターン数・島数・状態の表で表示します。名前から各ゲームのトップページに移動できます

## サイト設定

サイトの表示や、ゲーム全体に関わる設定を変更できます。保存するとすぐに反映されます。

| 項目 | 説明 |
| --- | --- |
| サイトタイトル | ヘッダやページのタイトルに表示されます (既定は「箱庭諸島２」) |
| 管理者名・連絡先メールアドレス | フッタに表示されます。空欄なら表示しません |
| 掲示板の URL・トップページの URL | フッタにリンクとして表示されます。空欄なら表示しません |
| 追加の NG ワード | 同梱のリストに加えて、島名・コメント・掲示板の投稿で拒否する語 (1 行に 1 つ) |
| ローカル掲示板 | 島ごとの掲示板を使うかどうか |
| タイムゾーン | 日時の入力と表示に使うタイムゾーン (例: `Asia/Tokyo`) |

:::note
Cloudflare 版で [KV スナップショットキャッシュ](/setup/kv-cache) を使っている場合、未ログインの閲覧者には、変更前の設定が最大 60 秒ほど表示されることがあります。
:::

## ゲームの設定

- **ゲーム設定**: 最終ターン数 (空欄で無期限) と、1 ターンの長さ (次のターン境界から反映) を変更できます
- **最終更新時刻の変更**: 日時 (datetime-local) か unix 秒で指定します。ターンの進むタイミングを調整したいときに使います
- **ログイン方法**: X / Discord / メールのログインを、それぞれ有効・無効にできます (環境変数で設定していない方法は選べません)

## プレイヤーの補助

- **資金・食料の最大化**: 島を選んで、資金と食料を最大値にします

## バックアップ

バックアップの一覧表示・作成 (ラベル指定可)・復元・削除ができます。詳しくは [バックアップ](/operation/backup) を参照してください。

## 開発用の機能

`HAKONIWA_DEBUG=true` のときは、トップページに「ターンを進める」ボタンが表示され、管理者は手動でターンを進められます。
