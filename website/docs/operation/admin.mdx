`HAKONIWA_ADMIN_EMAILS` に指定したメールアドレスでログインすると、`/admin` の管理画面を使えます。

## ゲームの開始と終了

- **新しいゲームを開始**: ゲーム名・開始日時・最終ターン・1 ターンの長さ (時間・分) を指定してゲームを始めます。すべて省略可能で、名前を省略すると「第 N 回」になります。現在のゲームが無いか、終了しているときだけ実行できます
- **このゲームを終了する**: 進行中のゲームを手動で終了させます (確認のチェックボックス付き)
- **このデータを削除**: 現在のゲームのデータを削除します

ゲームの流れについては [ゲームとシーズン](/operation/season) を参照してください。

## ゲームの状態と一覧

- **現役データ**: 現在のゲームの名前・ID・状態・ターン数・最終更新時刻・開始時刻・最終ターン・1 ターンの長さを表示します
- **ゲーム一覧**: 現在と過去のゲームを、名前・開始・終了・ターン数・島数・状態の表で表示します。名前から各ゲームのトップページに移動できます

## 設定の変更

- **ゲーム設定**: 最終ターン数 (空欄で無期限) と、1 ターンの長さ (次のターン境界から反映) を変更できます
- **最終更新時刻の変更**: 日時 (datetime-local) か unix 秒で指定します。ターンの進むタイミングを調整したいときに使います
- **ログイン方法**: X / Discord / メールのログインを、それぞれ有効・無効にできます (環境変数で設定していない方法は選べません)

## プレイヤーの補助

- **資金・食料の最大化**: 島を選んで、資金と食料を最大値にします

## バックアップ

バックアップの一覧表示・作成 (ラベル指定可)・復元・削除ができます。詳しくは [バックアップ](/operation/backup) を参照してください。

## 開発用の機能

`HAKONIWA_DEBUG=true` のときは、トップページに「ターンを進める」ボタンが表示され、管理者は手動でターンを進められます。
