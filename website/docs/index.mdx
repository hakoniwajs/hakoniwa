**箱庭諸島２** は、徳岡宏樹氏が 1990 年代末に公開した Web ブラウザゲームです。プレイヤーはそれぞれ自分の島を発見し、整地・植林・農場や工場の建設・ミサイル発射といった「開発計画」を登録します。一定時間ごとにターンが進み、すべての島で計画の実行、人口の増減、災害、怪獣の出現などが一斉に処理されます。

このプロジェクトは、オリジナルの Perl CGI を **TypeScript で書き直した移植版** です。ゲームのルールはオリジナル (ver2.3) のまま、今のインフラで手軽に動かせるようにしました。

## ボタンひとつで、自分の箱庭諸島を

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/hakoniwajs/template-cloudflare)

箱庭諸島を設置するには、かつては Perl が動くレンタルサーバーを借り、CGI のパーミッションを設定し……という手間がかかりました。TypeScript 版は **Cloudflare Workers** と **Durable Objects (SQLite)** の上で動くので、上の「Deploy to Cloudflare」ボタンを押すだけで、ゲーム本体・データベース・ターン進行 (Cron) がまとめて自分の Cloudflare アカウントに用意されます。

<Steps>
  <Step title="Deploy to Cloudflare ボタンを押す">
    GitHub と Cloudflare のアカウントで連携すると、テンプレートリポジトリが自分のアカウントにコピーされます。デプロイ画面で秘密鍵と管理者のメールアドレスを入力して、デプロイを実行します。
  </Step>
  <Step title="公開された URL を開いてログインする">
    `https://<名前>.<サブドメイン>.workers.dev` でゲームが公開されます。管理者のメールアドレスでログインします。
  </Step>
  <Step title="管理画面からゲームを開始する">
    `/admin` の「新しいゲームを開始」を押せば、あとは 6 時間 (設定で変更可) ごとにターンが自動で進みます。
  </Step>
</Steps>

Workers の無料プランの範囲でも、身内で遊ぶ程度の規模なら十分に動かせます。詳しくは [Cloudflare にデプロイする](/setup/cloudflare) を参照してください。

## 特徴

<CardGroup cols={2}>
  <Card title="オリジナルのルールを再現" icon="map">
    箱庭諸島 ver2.3 のルール (計画・災害・怪獣・記念碑・賞など) を移植しています。画像もオリジナルのものを同梱しています。
  </Card>
  <Card title="パスワード不要のログイン" icon="key">
    X (Twitter)・Discord・メール (マジックリンク) でログインできます。1 つのアカウントに複数の方法を連携することもできます。
  </Card>
  <Card title="シーズン制と過去のゲーム" icon="calendar">
    開始日時・最終ターン・1 ターンの長さを設定できます。終わったゲームは結果発表として読み取り専用で残り、次のゲームを始められます。
  </Card>
  <Card title="シェアしたくなる OGP 画像" icon="image">
    島のページを SNS でシェアすると、その島の地図を描いた画像がプレビューに表示されます。
  </Card>
  <Card title="スマートフォン対応" icon="smartphone">
    スマートフォンの画面幅でも、計画の入力や掲示板への記帳ができます。
  </Card>
  <Card title="Node.js でも動く" icon="server">
    ゲームロジックはランタイムから独立しています。`npx hakoniwa serve` で、自前のサーバーでも同じゲームを動かせます。
  </Card>
</CardGroup>
